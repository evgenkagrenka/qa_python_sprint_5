# qa_python_sprint_5

В данном проекте созданы автотесты для сервиса Stellar Burgers.

### Тесты проверяют:

1. Регистрацию (test_registration.py)
    - проверка регистрации пользователя с валидными данными
    - проверка регистрации пользователя с невалидным паролем (меньше 6 символов)

2. Авторизацию (test_authorization.py)
    - проверка авторизации пользователя по кнопке войти в аккаунт на главной странице
    - проверка авторизации пользователя по кнопке войти на странице личного кабинета
    - проверка авторизации пользователя с формы регистрации
    - проверка авторизации пользователя со страницы восстановления пароля

3. Переход авторизованного пользователя в личный кабинет (test_log_in_pers_acc.py)

4. Переход по клику на коснтруктор и логотип (test_pers_acc_to_constructor.py)

5. Проверка выхода из аккаунта (test_log_out.py)

6. Раздел Конструктор (test_constructor.py)
    - переход к разделу соусы
    - переход к разделу булки
    - переход к разделу начинки

### Структура проекта:

- папка tests
    - test_registration.py
    - test_authorization.py
    - test_log_in_pers_acc.py
    - test_pers_acc_to_constructor.py
    - test_log_out.py
    - test_constructor.py
- conftest.py (используемые фикстуры)
- curl.py (ссылки на тестируемые страницы сайта)
- data.py (тестовые данные)
- locators.py (используемые локаторы)

### Необходимо установить:

- фреймворк pytest
- драйвер для браузера WebDriver (Google Chrome)
- фреймворк Selenium

### Запуск тестов:

- запуск всех тестов: pytest -v tests/
- запуск выбранного теста pytest -v tests/"имя_выбранного_теста"
